# The First take's Hindi

Owner, 23 Oct 2026: "Get the hindi and hinglish modes working as well... everything should be ready before we resume the research on 25th".

**How it is used.** `design-system/story_take.py` looks up each English string from [first-take-script.md](first-take-script.md) in the table below. A string missing here shows in English in Hindi mode, and the build lists every string it could not find. The town's people's names come from the cast tables of [../content/first-take.md](../content/first-take.md).

**Hinglish** needs nothing here. It is the original mode: English words, with Hindi on the signs.

**This is a first draft for a native reader.** Read it aloud with Hindi-first players before anything ships.
